# Scientist Constraints

## Model

Use the same compact image-conditioned language model interface and output format for the primary benchmark. A future method may alter the training or alignment procedure, but should not improve the score merely by using a much larger pretrained vision-language model.

## Data

Use the deterministic synthetic scene splits generated by `data/synthetic_scenes.py`. Do not train on the evaluation split or add external labels for the synthetic benchmark.

## Evaluation

Write predictions in the same JSONL schema used by the current method: each record must contain `scene_id`, `image`, `objects`, `caption`, `qa_answer`, and `qa_label`. The evaluator must read artifacts from `outputs/`; it must not regenerate method predictions.

## Compliance Checklist

- [ ] Uses the provided synthetic train/eval scene splits.
- [ ] Does not train or tune on the eval split.
- [ ] Reports hallucination metrics and object-coverage constraint metrics.
- [ ] Keeps the prediction schema compatible with `scripts/evaluate.sh`.
- [ ] Does not reduce hallucination by emitting empty, refusal-heavy, or non-object responses.

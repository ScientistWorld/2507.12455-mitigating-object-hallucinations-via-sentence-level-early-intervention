# Hardening runs (iteration 11)

The gym was rebuilt on LLaVA-v1.5-7B / COCO; the audit files in the parent
`redteam/` directory concern the retired synthetic gym and are kept as the
"before" evidence of `HARDENING.md`.

- `job_main.sh`: preference construction (8,663 pairs), reference C-DPO,
  lr 5e-6 and half-data variants, re-prediction of two earlier 4.3K-pair
  adapters (seeds 42/43), post-hoc detector filters, first case run.
- `job_variants.sh`: candidate better variants (lr 3e-6 / 4e-6; C-DPO + NLL
  on the chosen sentence at lr 5e-6 / 8e-6).
- `job_test_enlarge.sh`: predictions on the 1,300 images added when the
  held-out test grew from 700 to 2,000 images; seed-43 replicate of the reference.
- `cases.py`: installs each candidate into an empty `outputs/` and runs the
  unmodified `bash scripts/evaluate_train.sh` and `bash scripts/evaluate_test.sh`
  with no arguments; results in `cases/<case>/`.
- `posthoc_filter.py`: inference-time detector filtering (brute-force check).
- `rank.py`: normalised rank (spread over the honest runs) and paired
  bootstrap against the reference; results in `summary.json`.

Prediction files live in `checkpoints/hardening/preds/` (not committed;
regenerated by the job scripts).
